# 曝光领地 · 模拟选手

用来验证比赛系统全流程（拉取代码 → 构建镜像 → 启动容器 → 对局 → 保存结果）的模拟选手仓库。仓库根目录就是一份标准提交：`README.md` + 入口 `main.py` + 其余源代码。

| 分支 | 选手 | 策略 |
|---|---|---|
| `main` | 模拟选手 A | 贪心：贴着己方图形区画收益最高的矩形，对手逼近就回家（改编自基准 Bot L2） |
| `player-b` | 模拟选手 B | 搜索：推演双方到达每一格的时间，只走对手追不上的路线（改编自基准 Bot L3） |

## 实现策略（模拟选手 A）

每回合按顺序判断：

1. **回家**：对手到达我任一轮廓格所需的回合数 ≤ 我回家的步数 + 2，就沿最短路回家。
2. **进攻**：8 步内有对手的轮廓，并且我在家或来得及回家，就去扫。
3. **拿道具**：加速道具已出现、在 12 步内、我比对手先到，就去拿。
4. **画圈**：在家时枚举矩形路线，用规则引擎算出闭合后实际新得的格子，按"新得价值 × 10 − 路线长度"选最好的一条。
5. **加速**：处于加速状态且前方连续 2 步同向、安全时，一回合走 2 格。

每回合找路线最多用 100 毫秒。

## 平台如何运行这个仓库

平台按提交时登记的提交号拉取代码，用平台统一的 Dockerfile 构建镜像（仓库里的 Dockerfile 不会被使用），然后在容器里执行 `python3 main.py`。

- 监听地址和端口来自环境变量 `BOT_HOST`（0.0.0.0）和 `BOT_PORT`（8000），令牌来自 `BOT_TOKEN`。`arena.sdk.run()` 会自动读取这些变量。
- 运行环境里已有与选手材料包同版本的 `arena` 包，不需要放进仓库。
- 需要第三方 Python 库时写进 `requirements.txt`，需要编译时提供 `build.sh`。两者都只在构建镜像时执行；对局时容器没有外网，根文件系统只读，可写目录只有 `/tmp`。

本地自检：把仓库放进选手材料包的 `bots/` 目录，运行 `python3 -m arena check bots/exposure-field-mock-player`。
